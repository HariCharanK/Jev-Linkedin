# Third-party code

The browser adapter and snapshot extractor are derived from Browser Use's
[Jev Ultrafast](https://github.com/browser-use/jev-ultrafast), commit
`1231850a0bf1a0c0341fe408ef1668dbbfdfac46`, under the MIT license.
Original browser.py, snapshot.js and license are retained in vendor/jev_ultrafast.
The Jev typed-choice API integration also adapts its model.py design.

Browser Harness 0.1.13 is a pinned runtime dependency. Its own license applies.
No upstream credentials, .env, Git history, recordings or user data were copied.
